### Improved

- Stream Manager is now called Broadcast Tech, and it can run any match that's on a stage from Admin → Match Schedule: check in, roll the seed, start and finish. Confirming a result still belongs to staff and tournament admins.

### Security

- Broadcast Techs no longer get the admin API, the admin tools on the Wizzrobe connector, reports or staff-only help. They keep their stage and match-running controls.

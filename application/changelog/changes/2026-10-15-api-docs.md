### Improved

- The API documentation at `/api/docs` now opens with a getting-started guide: how to make a token, what it can reach, and copy-paste examples for checking your token, reading a stage's schedule, signing up as crew and recording a result.
- Every endpoint in the API documentation now lists the errors it can return, says when it needs a token that isn't read-only, and says which community feature has to be turned on for it to work.
- Webhook deliveries are documented in the API docs: the exact JSON body, the headers, how to check the signature, and every event you can subscribe to.
- API sections are grouped and ordered by what you'd use them for, with event-day sections first.

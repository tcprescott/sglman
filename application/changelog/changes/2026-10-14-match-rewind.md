### Improved

- Edit Match is shorter. The five Clear buttons are gone: choose **Rewind…** from the dialog's ⋮ menu, pick the step to go back to, and everything after it is cleared together, so a match can't end up finished without having started.
- Re-rolling a seed is now **Clear seed…** in the same ⋮ menu, and it asks before clearing.
- "Cancel match…" is now "Call off match…", so it can't be mixed up with the dialog's Cancel button. Player acknowledgments moved out of the dialog; they're already in Match details.

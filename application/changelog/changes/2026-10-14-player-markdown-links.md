### Security
- Links in match comments and community event descriptions now always open in a new tab with a small "opens elsewhere" icon, and a link that only looked like a page in the app but pointed at another site no longer works as a link anywhere.
- Match comments and community event descriptions show text formatting, lists and links only. Headings read as bold text, and screenshots, tables and status badges show as the characters typed, so a comment can't pass for part of the app.
- An event title or location can no longer turn into a disguised link in the Discord message staff get when an event is submitted.

### New

- Staff can run tournament and event-day admin from the Wizzrobe MCP connector or the REST API: create, edit (including presets, the test flag, racetime and Discord event settings) and delete tournaments, manage their admins, coordinators and rosters, link or sync a Challonge bracket, and edit stages, volunteer positions and shifts, members and roles, equipment and payouts. Each action checks the same permissions as the Admin pages, and only reaches your own community. Reconnect the connector to see the new tools.

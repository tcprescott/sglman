- Communities can turn on Community Events: a listing of the meetups, panels
  and side events members are running during the event. It's off until a
  community has it switched on.
- Any member can submit an event with a start time, a length, a place and a
  formatted description. Staff review each one under Admin → Community Events
  and get a DM when one comes in. Events staff submit go straight up.
- The host gets a DM when their event is approved or rejected, with the reason
  if it's rejected. Hosts can edit a listed event without another review, and
  editing a rejected one sends it back to staff.
- Members can tap **Remind me** on any listed event to get a Discord DM shortly
  before it starts (30 minutes by default; staff can change this under
  Settings → Community Events). Subscribers also hear if it moves or is
  cancelled.
- The listing says plainly that these events are run by members and aren't
  endorsed by event staff.

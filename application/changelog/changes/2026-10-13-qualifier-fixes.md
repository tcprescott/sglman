### New

- Async qualifiers have a Qualifiers item in the side menu, so players can find
  open qualifiers without a link from staff.

### Fixed

- A qualifier's reviewers can now open the Qualifiers admin tab and see the
  qualifiers they review. It used to refuse them, and the "runs are waiting" DM
  sent them to that same refusal.
- Using a reattempt now draws a seed you haven't played in that pool. You only
  get the same seed again when the pool has none left.

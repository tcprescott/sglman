### New
- Async qualifiers have a Qualifiers item in the side menu, so players can find
  open qualifiers without a link from staff.

### Fixed
- A qualifier's reviewers can now open the Qualifiers admin tab and see the
  qualifiers they review. It used to refuse them, and the "runs are waiting" DM
  sent them to that same refusal.
- The Active switch in New Qualifier now does something. Every new qualifier
  used to start active whatever it was set to.
- Using a reattempt now draws a seed you haven't played in that pool. You only
  get the same seed again when the pool has none left.
- The DMs telling you a run was reviewed or forfeited for running out of time
  now open your runs on the qualifier page, not a leaderboard that stays hidden
  until the qualifier closes.
- A forfeited or disqualified run says so in My runs, where it used to read
  "Above par".
- Live races on the staff Qualifiers tab show their status in words (Racing,
  Room open) instead of `in_progress`.
- The review-backlog DM no longer says a waiting run stops the runner starting
  another, and the live-race tab no longer sends qualifier admins to Admin →
  Users (a staff-only tab) to fix a racer who couldn't be recorded.
